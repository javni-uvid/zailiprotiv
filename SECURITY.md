# Bezbednost / Security

**Srpski.** Ako nađeš bezbednosni propust na zailiprotiv.rs, nekom od poddomena ili u ovom kodu, prijavi ga
privatno: kartica **Security** ovog repozitorijuma → **Report a vulnerability**. Molimo te da ga ne objavljuješ
u javnom issue-u dok se ne ispravi. Odgovaramo u roku od nekoliko dana; projekat održava jedna osoba.

Pogrešan podatak na sajtu (glas, citat, ime) nije bezbednosni propust: za to otvori običan issue.

**English.** If you find a security flaw in zailiprotiv.rs, one of its subdomains or this code, report it
privately: this repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue
before it is fixed. Expect an answer within a few days; the project has one maintainer.

A wrong fact on the site (a vote, a quote, a name) is not a security flaw: open an ordinary issue for it.

What is guarded and how: [`docs/decisions/security.md`](docs/decisions/security.md).
